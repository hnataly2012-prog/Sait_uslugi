# Правовая стратегия

Статический сайт юридической практики: приветственный лендинг о сопровождении банкротства граждан, ИП и организаций.

## Состав

- `index.html` — страница сайта
- `css/style.css` — оформление
- `js/main.js` — меню, вкладки, калькулятор и форма заявки
- `favicon.svg` — значок вкладки

Цены, телефон, почта и Telegram в коде демонстрационные. Перед публикацией замените их в `index.html` и в объекте `CONTACT` / `TARIFFS` в `js/main.js`. Суммы в таблицах и в калькуляторе должны совпадать.

## Как открыть

Откройте `index.html` в браузере или запустите любой статический сервер из корня репозитория.

Форма не отправляет данные на сервер: она готовит письмо в почтовой программе и показывает текст заявки на странице.
